# [AR017] 需求设计说明书

| 字段 | 内容 |
|------|------|
| AR 编号 | AR017 |
| AR 主题 | CGW：长上下文门控的级联窗口 |
| 关联 SR | 在 AR016 GPU 最优组合上继续压缩决策段，且不降低安全/路由正确性 |
| 日期 | 2026-10-30 |
| 状态 | Approved（自动化 harnessX，用户已授权无需逐步确认） |

## 1. 背景

AR016 后 AGW_CASC_FAST + GPU offload：P50 1.753s、mean 3.054s。
其中 int8 门控仍约 1s。不同窗口的命中率与成本呈非单调关系：

- 128/192 极快，但单用命中不足；
- 384 命中高，但成本约 1.0s；
- 未命中只是回退 fp32 RDMP，**安全**。

## 2. 真实探测（shared 12 + gen 3 + needles 3）

| 级联 | 最终命中 | mean 门控 | P50 门控 | 平均级数 |
| --- | --- | --- | --- | --- |
| 192→384 | 18/18 | 698ms | 509ms | 1.28 |
| **128→384** | **18/18** | **361ms** | **200ms** | 1.22 |
| 128→192→384 | 18/18 | 309ms | 199ms | 1.28 |
| 192→384→512 | 18/18 | 470ms | 289ms | 1.28 |

128→384 以最少级数取得接近最优收益；更短的首级窗口把多数请求挡在极低开销。

## 3. 目标

- 新增 `decision_long_context_gate_windows`（默认 `[128, 384]`，空=沿用 AR016 单窗口）。
- 门控按窗口升序逐级执行：任一级判 FULL 即停；全部 no_reasoning 才回退 fp32 RDMP。
- 多个窗口共享同一 int8 会话（只复制 state 预算），不重复加载 427MB 模型。
- 真实验证：shared 12 路由与 RDMP 一致、0 激进翻转；端到端 CI 下界 >0 才 adopt。
