## 1. 背景与目标

AR002/AR003 已建立真实判定与运行时优化能力，但「小脑越用越强」与「大模型可复现实验」仍缺：
1. 台账未闭环为可训练数据集与可发布校准/路由模型；
2. 只有 1.5B 本机口径，缺 7B/14B 服务器实验矩阵与统计显著性；
3. 全新克隆者无法按文档一键复现实验。

本 AR 目标：
- **L1 飞轮**：`jev distill --flywheel` 全链路（采集→难例优先/对比样本→numpy 真训练（逻辑回归/MLP）→真实 bench 门控→发布或拒绝），退出码反映门结果；
- **L2 大模型实验与复现**：0.7B/1.5B/7B/14B × llama.cpp/vLLM 后端的配置矩阵、脚本、成对 bootstrap CI、环境/资产指纹、README + REPRODUCTION、CI 质量门；
- **L3 服务器侧训练**：kev-0.8B LoRA 训练脚本与配置（服务器执行，GPU 不可用环境不得伪造结果）。

## 2. 需求范围（骨架）

**In Scope（承接 AR002 迁移任务）：** T008 难例采样、T009 飞轮 CLI、T010 多基线、T012 报告升级、T013 README、T014 REPRODUCTION + 实验矩阵、T015 一键脚本/CI、T016 推送工具、T017 kev LoRA 服务器实验、T018 门验收；**AR002 T007 学习式 shadow 路由**（台账特征抽取 + numpy 真实训练 + shadow 对比报告，仅记录不切换控制流）。

**Out of Scope：** 新增在线服务协议、浏览器前端、模型权重入仓。

## 3. 功能需求（待细化）

- FR-L1 飞轮编排与门控（给定真实台账与真实 bench，门失败不得发布）
- FR-L2 多基线与统计显著性（brain_direct / cerebellum_only / cascade；成对 CI；指纹）
- FR-L3 大模型实验矩阵（7B/14B 配置真实可跑；14B 本机不跑但配置完整）
- FR-L4 复现文档与脚本（全新克隆 → doctor → unit → 真实 bench 子集）
- FR-L5 服务器 LoRA 训练（脚本 + 数据格式 + 评估口径；GPU 环境执行）
- FR-L6 学习式 shadow 路由（AR002 T007 承接）：用真实台账特征 + 真训练模型给出 shadow 路由建议，写入台账 `shadow_route` 并产出规则 vs 学习路由的对比报告（含成对 CI）；不得切换实际控制流
